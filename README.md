# 🚗 Park-Mate - A Parking Reminder App

A React Native Expo app to help users **save and navigate back to their parking spot** using **images, manual addresses, and GPS location tracking**.

## 📹 Demo
[![Watch the Demo](https://img.youtube.com/vi/m1AodjIc3uw/0.jpg)](https://youtube.com/shorts/m1AodjIc3uw?feature=share)
    

## ✨ Features
- 📍 **Save Parking Location** (Manually or via Photo)
- 🗺️ **View Car & User Location on Map**
- 🚀 **One-Click Navigation** to Parking Spot
- 📜 **Parking History** (List & Map View)
- ⚙️ **Settings** (Usage Guide & Privacy Policy)

## 🛠️ Tech Stack
- **React Native (Expo)**
- **Redux Toolkit**
- **Google Maps API**
- **Async Storage**
- **UUID for Unique Entries**

## 🚀 Getting Started

### 1️⃣ **Clone the Repo**
```sh
git clone https://github.com/your-username/your-repo.git
cd your-repo
```
### 2️⃣ **Install Dependencies**
```sh
npm install
```
### 3️⃣  **Run the App**
```sh
npx expo start
```
